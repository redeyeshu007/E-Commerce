# shared components

Cross-feature reusable components go here.
These components can be used across multiple features but are not generic enough
for `components/ui`.

Examples:

- `<ProductCard />` (used on listing, wishlist, and recommendations pages)
- `<PriceDisplay />` (used wherever a price needs formatting)
- `<GoldBadge />` (used to display gold purity markings)

Create a subdirectory per component family as the codebase grows.
